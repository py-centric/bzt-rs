Installation
============

bzt-rs is distributed as a standalone binary.

From Source
-----------
To build bzt-rs from source, you need the Rust toolchain installed.

.. code-block:: bash

   git clone https://github.com/v/bzt-rs.git
   cd bzt-rs
   cargo build --release

The binary will be available at `target/release/bzt-rs`.

Prerequisites
-------------
* Rust 2024 Edition or later.
* Cargo package manager.
